---
name: i18n
description: English/German bilingual support — switcher, persistence, and translation architecture
type: feature
---
- Two languages: English (default) + German. Switcher in header (desktop nav + mobile area).
- Architecture:
  - `src/i18n/translations.ts` — all UI strings keyed by section.
  - `src/i18n/data.ts` — `getIndustries(lang)` and `getServices(lang)` return DE or EN data (slugs unchanged).
  - `src/i18n/LanguageContext.tsx` — `LanguageProvider`, `useLanguage()`, `useT()`.
  - `src/components/LanguageSwitcher.tsx` — EN | DE toggle with Globe icon.
- Persistence: `localStorage` key `sabasam-lang`. Falls back to browser locale (de* → German).
- `<html lang>` updated on language change.
- LanguageProvider wraps app inside QueryClientProvider in `src/App.tsx`.
- When adding new UI strings: add to BOTH `en` and `de` blocks in `translations.ts`.
- When adding new industries/services: add to base `src/data/*.ts` (EN) AND mirror into `industriesDe`/`servicesDe` arrays in `src/i18n/data.ts` with the SAME slug.
