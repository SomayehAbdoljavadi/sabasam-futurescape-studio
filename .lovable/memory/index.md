# Project Memory

## Core
Sabasam E&C. Minimalist dark-futuristic, glassmorphism, Space Grotesk, gold accents on dark theme.
Forbidden: `lovable-tagger` Vite plugin (breaks local dev). CSS `@import` must be at top.
Nav: Home, Services, Target Industries, Sample Projects, About Us, Contact.
Bilingual EN/DE — every new UI string must be added to both languages in `src/i18n/translations.ts`.
